# AI-Powered Login Page Test Case Generator

## Project Overview
This project demonstrates how Prompt Engineering and AI tools can be used to generate software testing test cases for a Login Page.

The project includes:
- Positive test cases
- Negative test cases
- Security testing
- Password validation
- Forgot password scenarios
- UI/UX testing

## Tools Used
- ChatGPT
- Prompt Engineering
- QA Testing Concepts
- GitHub

## Objective
To automate and improve manual test case generation using AI prompts.

## Sample Prompt
Generate comprehensive test cases for a login page including:
- Positive testing
- Negative testing
- Security scenarios
- Forgot password functionality
- UI/UX validations

## Features Covered
- Functional Testing
- Validation Testing
- Security Testing
- Compatibility Testing
- Error Handling
